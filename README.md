# Power markets: trading and hedging a retail electricity portfolio

Code and data for my report in the HTW Berlin Summer School 2026

## How to run
1. Install uv and run `uv sync` in this folder to create the environment.
2. Open `power_market_project.ipynb` 
3. Select the `.venv` kernel and run Restart & Run All.

## Files
- `power_market_project.ipynb`: the full analysis (Exhibits 1–4 and Stages 1–7)
- `*.csv`: the case data (see `sources.csv` for the origin of each file)
- `pyproject.toml` and `uv.lock`: the Python packages and versions used
